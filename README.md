# Student Feedback Management System

A Java-based desktop application developed for Wachemo University (WCU) to efficiently manage, collect, and analyze student feedback.

## 🚀 Features
- **Student Portal:** Submit feedback and ratings anonymously or signed.
- **Admin Dashboard:** View, analyze, and process feedback reports.
- **Database Integration:** Connects seamlessly with MySQL database.

## 🛠️ Tech Stack
- **Language:** Java (Swing / AWT)
- **Database:** MySQL
- **Tooling:** NetBeans IDE, Launch4j (for `.exe` wrapper)

## 📁 Repository Structure
- `src/` - Core Java source code
- `lib/` - External JDBC/MySQL library dependencies
- `database.sql` - Database schema and tables
- `WCU_Feedback.exe` - Executable desktop application file

## 💻 How to Run
1. Import `database.sql` into your local MySQL server (phpMyAdmin / MySQL Workbench).
2. Ensure Java Runtime Environment (JRE) is installed.
3. Download and run `WCU_Feedback.exe` or `WCU_Feedback_Management_System.jar`.

   ### ⚠️ Note for Windows Users (SmartScreen Warning)
When you run `WCU_Feedback.exe` for the first time, Windows SmartScreen might pop up with a "Windows protected your PC" warning because the app is self-signed. 
To run it:
1. Click on **"More info"**.
2. Click **"Run anyway"**.
